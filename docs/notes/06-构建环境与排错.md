## 1. 本机已配置的环境（实际状态）

| 项 | 路径 / 版本 | 说明 |

| JDK 8 | `D:\dev\tools\jdk-8`（待装） | 1.12.2 / 1.16.5 必需 |
| JDK 21 | `D:\dev\tools\jdk-21`（待装） | 1.21.1（NeoForge）必需 |

## 3. 关键环境变量（PowerShell）

```powershell
# 所有 Gradle 缓存 / wrapper 下载都放 D 盘
[Environment]::SetEnvironmentVariable('GRADLE_USER_HOME','D:\dev\tools\gradle-home','User')
# 1.20.1 工程
$env:JAVA_HOME='D:\dev\tools\jdk-17'
```

CMD：
```cmd
setx GRADLE_USER_HOME "D:\dev\tools\gradle-home"
set JAVA_HOME=D:\dev\tools\jdk-17
```

> 不设 `GRADLE_USER_HOME` 的话，Gradle 会把几 GB 的依赖和 Minecraft 资源写到
> `C:\Users\<你>\.gradle`，违反本机"生成文件不进 C 盘"的规则。

## 4. 首次构建会发生什么

`gradlew build` 首次运行会：

1. 下载 Gradle 发行版（约 100 MB）到 `GRADLE_USER_HOME/wrapper`；
2. 下载 ForgeGradle、MCP 映射、Minecraft 客户端/服务端 jar（约 300 MB）；
3. 反编译 + 应用补丁（`build/` 下生成反编译源码，第一次 3~10 分钟）。

**离线/弱网建议**：
- 先只跑 `gradlew compileJava`（不下载 assets，不需要 natives）；
- `runClient` 才需要完整 assets（约 500 MB）。

## 5. 常见报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `Unsupported class file major version 69` | Gradle 用了 Java 25 | 设 `JAVA_HOME` 到 jdk-17，或 `org.gradle.java.home` |
| `Could not resolve net.minecraftforge:forge:...` | 仓库不通/版本号错 | 检查 `maven.minecraftforge.net`，版本写 `1.20.1-47.3.0` |
| `cannot find symbol: method getOrCreateTag()` | 用了 1.16+ 的 API 编 1.12.2 | 查版本差异表 |
| `cannot find symbol: class IUpgrade` | 没加 IE 依赖 / 没 deobf | `compileOnly fg.deobf(files(...))` |
| `NoClassDefFoundError: blusunrize/...` 运行时 | IE 没放进 `run/mods/` | 把 IE jar 复制进 `run/mods/` |
| `Mod file ... is missing mods.toml` | 资源目录结构错 | 确认 `src/main/resources/META-INF/mods.toml` |
| `Duplicate mods` | `run/mods` 里放了两个 IE | 只留一个 |
| 中文乱码 | 文件不是 UTF-8 | 所有 `.java` / `.json` 存 UTF-8 无 BOM |
| `OutOfMemoryError: Metaspace` | Gradle daemon 内存不足 | `org.gradle.jvmargs=-Xmx3G` |

## 6. 目录与缓存清理

```powershell
# 清 Gradle 缓存（会重新下载，慎用）
Remove-Item -Recurse -Force D:\dev\tools\gradle-home\caches

# 清单个工程
Remove-Item -Recurse -Force D:\dev\projects\IEAddon\versions\1.20.1\build
```

## 7. 运行测试的正确姿势

1. `gradlew build` 产出 `build/libs/<modid>-1.0.0.jar`；
2. 把 **IE 的正式 jar** 和你的 jar 一起放进 `run/mods/`；
3. `gradlew runClient`；
4. 进游戏后用 `/give @s mymod:my_tool` 测试，F3+H 看 NBT。

> 开发期 `run/mods/` 里的 IE 必须是**正式发布 jar**（不是 deobf 后的），
> 因为运行时是 SRG 名，deobf 过的 jar 反而会崩。
