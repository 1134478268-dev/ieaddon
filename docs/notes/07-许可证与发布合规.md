# 07 · 许可证与发布合规

> 依据：`https://github.com/BluSunrize/ImmersiveEngineering/blob/1.21.1/LICENSE`
> （Blu's License of Common Sense，©2017 BluSunrize，全文已抓取核对）

## 1. 对你（addon 作者）明确允许的

| 条款 | 原文含义 | 对你的意义 |
|---|---|---|
| 看代码、借鉴、复制片段 | "Look at the code, draw inspiration, copy bits of it" | 可以读 IE 源码学习 |
| Fork 并修改 | "Fork this repository and modify its code" | 可以自己改 IE（但不能重新分发，见下） |
| **写基于本项目和 API 的其他项目** | "Write other projects that base on this project and its API (if present) (This means Addons are totally cool)" | **做 addon 完全合规** |
| 提交 PR | — | 可以给 IE 贡献代码 |

## 2. 明确禁止的

| 条款 | 原文 | 对你的意义 |
|---|---|---|
| 声称代码是你的 | "Claim any of this code to be your property" | 不能把 IE 代码署名成你的 |
| **重新分发本项目（源码或编译产物）** | "Redistribute this project (source or compiled) without explicit permission" | **不能把你的 addon 打包成"含 IE"的整合包对外发**；不能把 IE jar 塞进你的发布物 |
| 大段复制代码不署名 | "Copy large sections ... without giving credit" | 复制了就要在 README 里注明 |
| **商业化** | "Monetize any of this project ... forbids paywalls or donations to restrict access" | **不能收费、不能设付费墙、不能"捐赠解锁"**；CurseForge 的 Points 系统除外 |
| 违反 Wheaton's Law | 作者保留撤销许可的权利 | 别做恶心事 |

## 3. 你必须遵守的

- **如果你用了任何 IE 的非 API 代码**（即 `common.*`、`client.*` 包里的类，或大段复制实现），
  **你的项目也必须"visible source"（源码可见）**。
  - 只调用 `api.*` 包里的接口/类 → **不触发**这条，你可以闭源。
  - 复制了 IE 的实现代码 → 必须开源可见。
- 复制代码片段要注明出处（credits）。
- 资源（贴图/模型）：
  - 始终注明原作者；
  - **复制前先征得同意**；
  - **addon 可以使用和 remix IE 的美术资源**，但仅限"作为 addon 使用"这一目的；拿不准就问。

## 4. 对你的发布策略的直接结论

| 你想做的事 | 是否允许 |
|---|---|
| 做一个 addon 放 CurseForge/Modrinth 免费下载 | ✅ |
| addon 闭源（只调 `api.*`） | ✅ |
| addon 开源（GitHub） | ✅（推荐） |
| addon 用 Patreon 付费墙解锁 | ❌ |
| 把 IE jar 一起打包进你的整合包发布 | ❌（除非 BluSunrize 明确许可） |
| 复制 IE 的贴图做自己的物品图标 | ⚠️ 仅限 addon 用途，且要注明；大量复制需询问 |
| 复制 IE 的 `UpgradeableToolItem` 实现到自己工程 | ⚠️ 会触发"源码可见"义务，需注明出处 |
| 在 addon 里直接 `import blusunrize.immersiveengineering.common.*` | ⚠️ 技术上能编译，但属于用内部实现 → 触发开源义务 + 版本升级易崩 |

## 5. 建议的 addon 许可证

- 想让别人也能二次开发：**LGPL-3.0** 或 **MIT**。
- 想保留控制权但允许整合包收录：**All Rights Reserved + 明确允许整合包分发**。
- 无论选哪个，**不要**与 IE 的许可证冲突（尤其别声明"禁止任何人修改"再复制 IE 代码）。

## 7. 一句话合规口诀

> **只调 `api` 包 → 可闭源；碰了 `common`/复制实现 → 必须开源；任何时候都不能收费、不能打包 IE 本体。**
