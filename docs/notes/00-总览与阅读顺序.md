## 四、最快的检索方式

查某个 API 怎么用，直接搜源码：

```bash
# 找接口定义
rg "interface IUpgradeableTool" D:\dev\projects\IEAddon\docs\IE-src-1.20.1\src\api

# 找 IE 自己的实现（最好的参考）
rg "implements IUpgradeableTool" D:\dev\projects\IEAddon\docs\IE-src-1.20.1\src\main

# 找某个 NBT key 的含义
rg "\"speed\"" D:\dev\projects\IEAddon\docs\IE-src-1.20.1\src\main\java\blusunrize\immersiveengineering\common\items
```

> 注意：`src/api` 是**给你编译依赖用的 API 面**；`src/main` 是 IE 内部实现，只读不改。
> 你的 addon 只应依赖 `blusunrize.immersiveengineering.api.*`，依赖 `common.*` 属于"用到内部实现"，
> 升级 IE 版本时极易崩，且许可证要求你开源（见 `07`）。

## 五、三条硬约束（先记住）

1. **IE 的 API 每个大版本都会重写**：1.12.2 的 `IUpgradeableTool.recalculateUpgrades(ItemStack)` 到 1.20.1 变成
   `recalculateUpgrades(ItemStack, Level, Player)`。不存在"一套 Java 代码通吃 1.12~1.21"。
2. **多版本 = 多工程**，共享的是资源、lang、设计、配方，而不是 Java 源码。
3. **Blu's License of Common Sense 允许做 Addon**，但用了非 API 代码就必须开源可见、禁止付费墙。
   见 `07-许可证与发布合规.md`。
