# 05 · 工具与装备扩展点（你的主战场）

> 这一章的所有代码都以 IE 1.20.1 的官方实现为蓝本（`common/items/ToolUpgradeItem.java`、
> `common/items/UpgradeableToolItem.java`、`common/items/DrillItem.java`），并给出 1.12.2 的等价写法。

## 1. IE 升级系统的模型

IE 的"升级"不是继承，而是**字符串标签 + NBT**：

```
工具实现 IUpgradeableTool，声明自己的 upgradeType（例如 "DRILL"）
        │
升级物品实现 IUpgrade，getUpgradeTypes() 返回 {"DRILL", ...}
        │
玩家在工程师工作台把升级放进槽位 → 工作台调用 tool.recalculateUpgrades(...)
        │
遍历工具内部物品栏里的每个 IUpgrade：类型匹配 + canApplyUpgrades → applyUpgrades(stack, upgrade, nbt)
        │
最终 nbt 被写进 stack 的 "upgrades" 标签，工具运行时读这个标签决定行为
```

**关键点**：`applyUpgrades` 只改传入的 `CompoundTag modifications`，**不要**直接改 `target`。
这样"移除升级后重算"才能正确还原。IE 官方注释写得很明确。

## 2. 写一个升级物品（1.20.1）

```java
public class MyUpgradeItem extends Item implements IUpgrade {
    private final String toolset;      // 与工具的 upgradeType 对应
    private final int maxStack;

    public MyUpgradeItem(String toolset, int maxStack, Properties props) {
        super(props);
        this.toolset = toolset;
        this.maxStack = maxStack;
    }

    @Override
    public int getMaxStackSize(ItemStack stack) { return maxStack; }

    @Override
    public Set<String> getUpgradeTypes(ItemStack upgrade) {
        return Set.of(toolset);
    }

    @Override
    public boolean canApplyUpgrades(ItemStack target, ItemStack upgrade) {
        // 返回 false 表示这个升级不能装到这件工具上（例如已有冲突升级）
        return true;
    }

    @Override
    public void applyUpgrades(ItemStack target, ItemStack upgrade, CompoundTag modifications) {
        // 只写 modifications，不要写 target
        modifications.putBoolean("my_flag", true);
        modifications.putFloat("my_speed", upgrade.getCount() * 1.5f);
    }

    @Override
    public void appendHoverText(ItemStack stack, Level level, List<Component> tips, TooltipFlag flag) {
        tips.add(Component.translatable("item.mymod.my_upgrade.desc").withStyle(ChatFormatting.GRAY));
    }
}
```

### 1.12.2 等价写法

public class MyUpgradeItem extends Item implements IUpgrade {

## 3. 写一个可升级工具（1.20.1）

这是 addon 里最复杂的部分，因为 IE 的 `UpgradeableToolItem` / `InternalStorageItem` 在
`common` 包（内部实现），**不能**被 addon 继承。你要自己实现：

1. `IUpgradeableTool` 的 6 个方法；
2. 工具内部的 `IItemHandler`（装升级/钻头）；
3. `getWorkbenchSlots` 返回工作台槽位。

### 3.1 最小可用实现

```java
public class MyToolItem extends Item implements IUpgradeableTool {
    private static final String UPGRADES = "upgrades";
    private static final String INV = "inventory";
    public static final String TOOLSET = "MY_TOOL";
    private static final int SLOTS = 3;

    public MyToolItem(Properties props) { super(props); }

    // ---------- 内部物品栏（升级槽） ----------
    public IItemHandler getInventory(ItemStack stack) {
        return new ItemStackHandler(SLOTS) {
            @Override protected void onContentsChanged(int slot) { /* 标记同步 */ }
        }; // 生产环境应把 handler 缓存进 stack 的 capability
    }

    // ---------- IUpgradeableTool ----------
    @Override
    public CompoundTag getUpgrades(ItemStack stack) {
        return stack.getOrCreateTagElement(UPGRADES);
    }

    @Override
    public void clearUpgrades(ItemStack stack) {
        stack.removeTagKey(UPGRADES);
    }

    @Override
    public void finishUpgradeRecalculation(ItemStack stack) { }

    @Override
    public void recalculateUpgrades(ItemStack stack, Level level, Player player) {
        if (level.isClientSide) return;
        clearUpgrades(stack);
        IItemHandler inv = getInventory(stack);
        CompoundTag tag = new CompoundTag();
        for (int i = 0; i < inv.getSlots(); i++) {
            ItemStack u = inv.getStackInSlot(i);
            if (u.getItem() instanceof IUpgrade upg
                    && upg.getUpgradeTypes(u).contains(TOOLSET)
                    && upg.canApplyUpgrades(stack, u)) {
                upg.applyUpgrades(stack, u, tag);
            }
        }
        stack.getOrCreateTag().put(UPGRADES, tag);
        finishUpgradeRecalculation(stack);
    }

    @Override
    public boolean canTakeFromWorkbench(ItemStack stack) { return true; }

    @Override
    public void removeFromWorkbench(Player player, ItemStack stack) { }

    @Override
    public boolean canModify(ItemStack stack) { return true; }

    @Override
    public Slot[] getWorkbenchSlots(AbstractContainerMenu container, ItemStack stack,
                                    Level level, Supplier<Player> getPlayer, IItemHandler toolInventory) {
        return new Slot[]{
                new UpgradeSlot(toolInventory, 0, 80, 20, stack),
                new UpgradeSlot(toolInventory, 1, 100, 20, stack),
                new UpgradeSlot(toolInventory, 2, 120, 20, stack)
        };
    }

    /** 只允许放本工具类型的升级 */
    public static class UpgradeSlot extends Slot {
        private final ItemStack tool;
        public UpgradeSlot(IItemHandler handler, int index, int x, int y, ItemStack tool) {
            super(handler, index, x, y);
            this.tool = tool;
        }
        @Override
        public boolean mayPlace(ItemStack stack) {
            return stack.getItem() instanceof IUpgrade upg
                    && upg.getUpgradeTypes(stack).contains(TOOLSET);
        }
    }
}
```

### 3.2 让工具"有电"（FE 能量）

```java
public class MyToolItem extends Item implements IUpgradeableTool {
    public static final int CAPACITY = 100_000;

    // 1.20.1：给 ItemStack 挂能量 capability（在 Mod 构造器里注册）
    // 或者直接实现 IItemHandler 之外的 IEnergyStorage：
    public static class Energy implements IEnergyStorage {
        private final ItemStack stack;
        public Energy(ItemStack stack) { this.stack = stack; }
        @Override public int receiveEnergy(int max, boolean simulate) {
            int cur = stack.getOrCreateTag().getInt("energy");
            int add = Math.min(max, CAPACITY - cur);
            if (!simulate) stack.getOrCreateTag().putInt("energy", cur + add);
            return add;
        }
        @Override public int extractEnergy(int max, boolean simulate) {
            int cur = stack.getOrCreateTag().getInt("energy");
            int sub = Math.min(max, cur);
            if (!simulate) stack.getOrCreateTag().putInt("energy", cur - sub);
            return sub;
        }
        @Override public int getEnergyStored() { return stack.getOrCreateTag().getInt("energy"); }
        @Override public int getMaxEnergyStored() { return CAPACITY; }
        @Override public boolean canExtract() { return true; }
        @Override public boolean canReceive() { return true; }
    }
}
```

注册 capability（1.20.1）：

```java
@SubscribeEvent
public static void attachCaps(AttachCapabilitiesEvent<ItemStack> event) {
    if (event.getObject().getItem() instanceof MyToolItem) {
        event.addCapability(new ResourceLocation(MODID, "energy"), new ICapabilityProvider() {
            private final Energy energy = new Energy(event.getObject());
            @Override public LazyOptional<IEnergyStorage> getCapability(Capability<IEnergyStorage> cap, Direction side) {
                return cap == ForgeCapabilities.ENERGY ? LazyOptional.of(() -> energy) : LazyOptional.empty();
            }
        });
    }
}
```

### 3.3 1.12.2 的差异

| 1.20.1 | 1.12.2 |
|---|---|
| `CompoundTag` / `getOrCreateTagElement` | `NBTTagCompound` / `getOrCreateSubCompound` |
| `ItemStackHandler`（Forge） | `ItemStackHandler`（Forge 也有） |
| `Slot(IItemHandler, int, int, int)` | `Slot(IInventory, int, int, int)` |
| `mayPlace` | `isItemValid` |
| `recalculateUpgrades(stack, level, player)` | `recalculateUpgrades(stack)` |
| `LazyOptional`（1.13+） | 直接返回 `IEnergyStorage` / `null` |

## 4. 电力装备：`IElectricEquipment`

让护甲/工具"防电"（被 IE 的电弧、特斯拉线圈击中时减免伤害）：

```java
public class MyArmorItem extends ArmorItem implements IElectricEquipment {
    public MyArmorItem(...) { super(...); }

    @Override
    public void onStrike(ItemStack equipped, EquipmentSlot slot, LivingEntity owner,
                         Map<String, Object> cache, @Nullable DamageSource dmg,
                         ElectricSource desc) {
        if (dmg == null) return;
        // 例如：把伤害减半（desc 里有强度信息）
        dmg.setAmount(dmg.getAmount() * 0.5f);
    }
}
```

> `ElectricSource` 提供 `getStrength()` 等信息；不同 IElectricEquipment 之间可以通过 `cache` 协作
> （例如"护甲 + 背包"叠加）。

## 5. 自定义钻头：`IDrillHead`

```java
public interface IDrillHead {
    boolean beforeBlockbreak(ItemStack drill, ItemStack head, Player player);
    void afterBlockbreak(ItemStack drill, ItemStack head, Player player);
    int getMiningLevel(ItemStack head);
    float getDestroySpeed(ItemStack drill, ItemStack head);
    void damageHead(ItemStack head, int amount, LivingEntity entity);

```

实现后，玩家把钻头放进 IE 钻头的工作台槽位即可使用。这是"新工具"最容易出彩的方向。

## 6. 调试技巧

1. **NBT 看不到**：按 F3+H 开启高级提示，或装 NBT 查看 mod；IE 的工具升级存在 `upgrades` 标签。
2. **工作台里没有槽位**：`getWorkbenchSlots` 返回 null 或槽位坐标越界（GUI 是 176x166）。
3. **升级不生效**：`recalculateUpgrades` 只在服务端跑（`if (level.isClientSide) return;`），
   客户端靠同步；确认你的工具在 `recalculateUpgrades` 后调用了 `finishUpgradeRecalculation`。
4. **物品变回原版**：模型 JSON 的 `textures.layer0` 路径写错，F3+T 重载资源包看日志。
